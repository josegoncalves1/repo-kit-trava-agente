# TERMO DE NÃO ENTREGA

Use este formulário quando o trabalho **não pode** ser declarado entregue sem
mentir, maquiar ou pular prova. Ele existe para tornar o bloqueio útil.

Se você é agente: não transforme este termo em pedido de desculpa comprido.
Preencha com fatos verificáveis. O objetivo é deixar claro o que aconteceu,
o que falta e qual decisão humana destrava o próximo passo.
